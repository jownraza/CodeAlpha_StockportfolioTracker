# CodeAlpha Task 3: Stock Portfolio Tracker

This is a Python Stock Portfolio Tracker developed as part of the CodeAlpha Internship Task 3.

## Project Description
The program helps users track their stock investments.
Users can add stocks with quantity and buy price, and view total investment in their portfolio.

## Features
- Add new stocks with name, quantity, and buy price
- Update quantity if same stock is added again
- View complete portfolio with total investment value
- Input validation for numbers

## How to Run
 Make sure you have Python 3 installed
Run the command: `2nd.py`
